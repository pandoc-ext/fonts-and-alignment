## Left-aligned Text

```markdown
::: {.pfa-align-left}
This block of text is _left-aligned_.
:::
```

::: {.pfa-align-left}

:::

## Explicit Line Break Preservation

```markdown
::: {.pfa-align-center}
This block of text\
is _center-aligned_\
while preserving explicit line breaks.
:::
```

:::
